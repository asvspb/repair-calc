# 📂 Библиотека ролевых промптов — Repair Calculator

Иерархия ИИ-агентов проекта. Промпты версионируются как код: правка промпта = PR + ревью.

## Иерархия

```
                    ЧЕЛОВЕК (владелец)
                          │
        ┌─────────────────┴──────────────────┐
        │            LEVEL 1                 │
        │  techlead-architect.md             │  ← координатор: ТЗ, ревью, git, merge
        │                                    │
   ┌────┴─────┬───────────┬──────────┬──────────┐
   │  LEVEL 2 │           │          │          │
   │ coder.md │ debugger  │ designer │ analyst  │  ← исполнители: один агент = одна роль
   │          │ tester    │ doc-keeper│         │
   │          │ release-eng│ reqs-keeper│       │
   └──────────┘           └──────────┘          │
                                                │
                    ОСОБЫЙ КОНТУР (вне иерархии):
                    pentester.md  ← независимый аудит;
                                     аппрув фикс-PR — только после чистого re-test
```

**Правила иерархии:**

- LEVEL 2 не общается между собой напрямую — только через архитектора (handoff = файлы `devAI/spec/` + записи в `devAI/developer_log.md`).
- Пентестер независим: репортит человеку + архитектору; архитектор НЕ правит находки сам — превращает в ТЗ кодеру.
- Одна сессия = одна роль. Не смешивай роли в одном промпте.

## SSOT-иерархия (для всех ролей)

**код > AGENTS.md > промпт роли.** Промпт расходится с AGENTS.md → главнее AGENTS.md;
AGENTS.md расходится с кодом → главнее код, дрейф = задача на исправление документации.

### Известные дрейфы

Актуальный реестр дрейфов ведётся в [docs/README.md](../docs/README.md) (секция
«Известные дрейфы»). Дрейф документации ≠ повод подыграть: создай задачу на исправление.

### Недоступно в этой среде (НЕ ссылаться)

CI/CD (GitHub Actions не настроен для gates), SonarQube, Codegraph MCP, сторонние ревью-боты.
Единственные gates: `pnpm test`, `pnpm run lint`, `pnpm run lint:deps` (в корне).
