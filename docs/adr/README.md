# 📐 Architecture Decision Records

ADR — короткая неизменяемая запись архитектурного решения: контекст → решение →
последствия. Формат [MADR](https://adr.github.io/madr/). Отвечает на вопрос
«почему сделано именно так» — то, чего нет в ARCHITECTURE.md (там — как устроено).

## Правила

1. **Неизменяемость:** принятый ADR не редактируется. Изменение решения = новый ADR
   со статусом Accepted + пометка «заменяет ADR-NNNN» + у старого статус
   `Superseded by ADR-NNNN`.
2. **Нумерация:** `NNNN-kebab-slug.md`, монотонная, без дыр и переиспользования номеров.
3. **Статусы:** `Proposed` (обсуждается) → `Accepted` (действует) → `Deprecated` /
   `Superseded by ADR-NNNN`.
4. **Один ADR = одно решение.** Несколько решений = несколько ADR.
5. Шаблон: [\_templates/adr.md](../_templates/adr.md).
6. ADR пишет тот, кто принимает решение (архитектор), в том же PR, где решение
   внедряется, если решение кода касается.
